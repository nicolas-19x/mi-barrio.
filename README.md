# mi-barrio.

Juego: abrí `Mi_Barrio.html` en el navegador.

**Multijugador en la misma red wifi:** `node server/server.js` y abrí en cada celular la dirección que muestra. Detalles en [`server/README.md`](server/README.md).

**Para progresar:** en el celular, la pestaña **📱 Apps** trae Metas (qué sigue), Mis vehículos, Marketplace, Agencia, COSEVI, Mi negocio, Mi soda, CoopeBarrio, Asociación, Empresas, Bienes raíces, Patrimonio, Fundación y Mi casa.

**Para programar:** el código fuente está en [`src/`](src/README.md), separado por sistemas. Se edita ahí y se arma el juego con `python3 build.py`.
