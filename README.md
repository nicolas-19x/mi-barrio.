# mi-barrio.

Juego: abrí `Mi_Barrio.html` en el navegador.

**Multijugador en la misma red wifi:** `node server/server.js` y abrí en cada celular la dirección que muestra. Detalles en [`server/README.md`](server/README.md).

**Para progresar:** en el celular, la pestaña **📱 Apps** trae Metas (qué sigue), Mis vehículos, Marketplace, Agencia, COSEVI, Mi negocio, CoopeBarrio, Asociación y Mi casa.
